# UI tools from a "5 websites" video: are they useful for Sentio?

- **Date:** 2026-11-06.
- **The question:** Karan asked whether five tools from a social video would help Sentio's interface.
- **Why fit matters:** Sentio's frontend is plain HTML, CSS and JavaScript with **no build step**, and it runs **locally, often offline**. A tool has to work in that setup.
- **How I checked:** npm package data and web searches. Reddit blocked the research tool's live search, so there is no community opinion here.

| Tool                                               | What it is                                                                                       | Fits Sentio?                                                                              | Verdict                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Anime.js** (`animejs` 4.5, MIT, no dependencies) | A JavaScript animation library                                                                   | Yes technically: plain JS, and one file could be bundled into the project for offline use | **Not needed now.** Every motion Sentio needs (hover, press, fades, the arrival of a message) is done in CSS with the shared timing values (`--dur`, `--ease`). A library would add weight and tempt us into decorative motion, which DESIGN.md rules out. Worth revisiting only for one deliberate moment, such as animating the topic-mastery bars. |
| **Motion** (`motion` 14.9, MIT)                    | An animation library, best known for React (it builds on Framer Motion)                          | Partly: it has a plain-JS `animate()`, but the package depends on `framer-motion`         | **Not needed**, for the same reasons as Anime.js, and it's heavier.                                                                                                                                                                                                                                                                                   |
| **Bklit UI**                                       | React chart components installed through the shadcn command-line tool (built on Visx and Motion) | **No:** it needs React and a build step                                                   | **Can't use directly.** Its charts could inspire a calmer Progress page drawn in plain SVG.                                                                                                                                                                                                                                                           |
| **Coconut UI**                                     | Most likely the Coconut Design System for Flutter (mobile apps), or an unrelated Haxe library    | **No:** wrong platform                                                                    | **Not applicable.**                                                                                                                                                                                                                                                                                                                                   |
| **Manus** (manus.ai)                               | A general paid AI agent that builds things on its own                                            | **No:** it would be a second assistant working in the same code                           | **Not useful here.** Claude Code, the Impeccable design skill, Watermelon and Figma already cover building and design.                                                                                                                                                                                                                                |

## What was done instead (2026-11-06)

The research in [research-trust-and-clarity.md](research-trust-and-clarity.md) pointed at clutter, not missing animation, so the night's work applied the decluttering plan:

- **Library rows:** one **Study** button plus a **More** menu (Study slides, Preview, Topics, Delete) instead of five buttons on every row.
- **Study toolbar:** one **Practise** menu (Try a quiz, Make flashcards) instead of two equal buttons, and **End session** as a quiet red text link.
- **Shared menu behaviour:** menus close after a choice, on an outside click and on Escape, and focus returns to the menu button.
- **Empty Library:** an "Add your first lecture" heading, one sentence, and a faint preview of what ready lectures look like.
